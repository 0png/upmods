# 🏎️ upmods V1.0 Technical Specification

## 1. Full-Screen Immersive UI
* **Viewport Dominance**: Leverage Ink's `Box` component with `flexGrow: 1` to occupy the entire terminal screen.
* **Structured Bordered Table**: 
    - **No Loose Text**: Replace raw text alignment with a formal grid system using solid or rounded borders.
    - **Fixed Columns & Dividers**: Implement vertical and horizontal dividers between fields (Name, Current, Target, Status).
    - **Adaptive Layout**: Dynamically calculate column widths based on terminal dimensions to prevent layout breaking.
* **Welcome Banner**: Feature a prominent ASCII Art `UPMODS` header for brand identity.
* **5-Step Progress Footer**: A persistent bottom status bar tracking execution stages:
    - `Step 1/5: Scanning local files...`
    - `Step 2/5: Fetching metadata...`
    - `Step 3/5: Decision & Filtering...`
    - `Step 4/5: Batch downloading/migrating...`
    - `Step 5/5: Task complete!`

## 2. Interactive Selection (User Control)
* **Multi-select UI**: 
    - Provide a checklist interface where users toggle mods using `Space`.
    - Execute updates only for selected items upon pressing `Enter`.
    - **Smart Default**: All items selected by default to maintain efficiency for power users.

## 3. Core Logic Enhancements
* **Cross-Version Migration Logic**:
    - Automatically physically move "Up to date" compatible mods to the target directory.
    - Display status as `[MIGRATED]` for these files to confirm they skipped the download queue.
* **Version Name Sanitizer**: 
    - Strip redundant prefixes/suffixes (e.g., `mc`, `+fabric`) via Regex before rendering the table.
* **Final Checksum Validation**: 
    - Perform a secondary SHA-1 hash check post-download to ensure integrity during high-speed transfers.

## 4. UI Status Encoding
* `UPDATING` (Cyan): Fetching remote resources.
* `MIGRATED` (Bright Green): Compatible version found; physically moved.
* `IDENTIFIED` (Dim Gray): Local/Private mod detected; skipped.
* `ERROR` (Red): Download or checksum validation failed.
